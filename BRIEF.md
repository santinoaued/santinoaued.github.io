# Brief - Portfolio de Santino Aued

## Objetivo
Un único sitio con dos públicos:
- Modo Game Developer: industria de videojuegos (estudios, reclutadores, colegas).
- Modo Web Developer: comercios y emprendimientos locales que buscan una web.

## Funcionalidades
1. Switch de modo en la parte superior: Game Developer / Web Developer.
   - Cambia título principal, bajada, tecnologías y sección de proyectos.
   - El color de acento cambia levemente según el modo (verde en juegos, marrón madera en web).
2. Switch de idioma: ES / EN. Traduce todo el sitio.
3. Ambos estados se reflejan en la URL (?mode=game|web&lang=es|en) para poder compartir un link directo a cada versión. Si no hay parámetros: modo game, idioma es.
4. Recordar la última elección del visitante en localStorage (envuelto en try/catch). La URL tiene prioridad sobre lo guardado.
5. El cambio de modo e idioma no recarga la página.
